Privacy-First Architecture by Design

Grammora strictly ignores password inputs (type="password"), credit card numbers, OTP fields, and developer-ignored elements. Text is never streamed keystroke-by-keystroke; only bounded sentences are sent after you stop typing. User writing is never logged or stored.

Answers & Details

Frequently Asked Questions

Do I need my own Groq or Gemini API key?

No! The extension comes pre-configured to connect automatically to the hosted Grammora cloud gateway at https://grammora-omega.vercel.app. You can start using it immediately after unzipping and loading into Chrome.

Is Grammora really 100% free and open-source?

Yes! Grammora is fully open-source under the MIT License. The entire source code for both the Chrome Extension and the AI Gateway backend is available on GitHub.

Which browsers are supported?

Any Chromium-based web browser: Google Chrome, Brave, Microsoft Edge, Arc, Opera, and Vivaldi.

Can developers run their own private backend server?

Absolutely. You can clone the GitHub repo, run npm run dev:server locally, and change the API Gateway endpoint in the Grammora extension settings popup to http://localhost:3001.
